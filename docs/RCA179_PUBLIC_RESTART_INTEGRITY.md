# RCA179 public-only real process restart and state integrity test
RCA178 state parser and token verifier, with a SHA-256 digest pinned by the test controller. Verify the same bounded byte sequence before parsing. The controller launches a loopback-only SDK server as a separate subprocess, confirms valid reads and denials, kills it using SIGKILL, and starts a fresh process using the same listener and expected digest. A valid but obsolete state and a modified revocation list are denied. Restore the exact current state to recover legitimate reads while revoked and retired credentials remain denied. The parent keeps the expected digest only within the test. This is not a production trust anchor, signed state update protocol, power-loss persistence, external custody, or protection against rollback of both state and anchor. No private data/keys, external OAuth, changes to GitHub connections, or approval prompts. Source: https://theupdateframework.github.io/specification/latest/ ; https://docs.python.org/3/library/os.html ; https://www.rfc-editor.org/rfc/rfc7009.html
