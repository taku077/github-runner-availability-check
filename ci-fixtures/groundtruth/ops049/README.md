The public GitHub-hosted Ubuntu job reads the actual OPS048 metadata receipt from Run 42633504230. It pins SHA256 22803ace1b7e9b8cb2b0a681759c2775173c3f924e2dfe8aec96ad818d09673b and source EVTX SHA256 + original receipt SHA256 + EventRecordID on each of two public synthetic Windows test samples. The 4 self-generated benign test actions are not independently adjudicated. It rejects replaced sources, missing records, duplicate IDs, fake scores, misleading normal labels, rule completeness claims, and changed analyzer output. It never sends raw EVTX or JSONL and never touches a user PC.

Future *manual independent admission* requires (a) intact original EVTX, source identity/channel/EventRecordID and acquisition timeline, (b) independently authenticated ground truth for EACH target event with adjudicator, original evidence, method and reviewer independence from the detector result, (c) a predeclared scoring unit (distinct event vs correlation sequence), complete source population and coverage, with negative denominator, unknown labels excluded, and duplicate/multi-rule alert treatment, (d) both attack-positive and independently normal controls plus observation completeness, and (e) confidence intervals, sampling/reproducibility and known limitations. An event file's MITRE technique name is NOT event-level ground truth. This tool DOES NOT admit even a self-declared independent label or calculate any metric. A future separate reviewed implementation may do so only when those prerequisites are independently checked.
